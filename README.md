<h1 align="center">SoundTester</h1>
<h2>Десктопное приложение для тестирования устройств ввода и вывода звука ПК.</h2>
<h3>В фукционал приложения входит генерация звука и его воспроизведение на устройствах вывода звука, проверка баланса звука (смещение влево-вправо), монииторинг микрофона, отображение спектрограмм и осциллограмм, а аткже их сохранение в формате "png". При разработке использовалась библиотека [NAudio](https://github.com/naudio/NAudio)</h3>
